### II.2 The counterexample ROT4  [PROVED; machine-exact]

**Definition.**  For v ≥ 2 in octave O_m = (2^m, 2^{m+1}] with offset
p := v − 2^m − 1 ∈ [0, 2^m), let the quarter be q(v) := ⌊4p/2^m⌋ and
the phase residue r(v) := (q(v) − m) mod 4.  Team A := {v : r(v) ∈
{0, 1}}, team B := {v : r(v) ∈ {2, 3}}.  (A's half-octave interval
rotates by one quarter per octave.)

**(R1) Exact balance / everywhere-split.**  Each quarter of O_m has
exactly 2^{m−2} values (m ≥ 2), so |A ∩ O_m| = |B ∩ O_m| = 2^{m−1}
exactly [trivial; machine: e131 split, octaves 4..20].  Both teams'
per-block presence diverges — ROT4 is Case-2/everywhere-split, and
each team's within-octave material is a contiguous run (maximally
concentrated locally).

**(R2) Window-diffuse.**  Hand bound: every ratio-2 window
W = (a, 2a] misses ≥ 2^{oct(a)}/8 − O(1) ≥ a/16 − O(1) values of
EACH team.  Proof: let m = oct(a), L1 = |W ∩ O_m| = 2^{m+1} − a,
L2 = |W ∩ O_{m+1}| = 2a − 2^{m+1}.  Case (i) L2 ≥ (5/8)·2^{m+1}: W
contains the bottom 5/8 of O_{m+1}; a team's octave material is an
arc of length 1/2 of the octave circle, which covers at most 1/2 of
any set, so ≥ 5/8 − 1/2 = 1/8 of O_{m+1} inside W is missed.  Case
(ii) L2 < (5/8)·2^{m+1}, i.e. a < (13/8)·2^m, so L1 = 2^{m+1} − a >
(3/8)·2^m: W contains the top 3/8 of O_m.  If
team T's arc misses ≥ 1/8 of it, done.  Otherwise T's arc covers the
top 3/8 up to < 1/8, forcing the arc into position [1/2, 1] (r = 2;
the wrapped arc [3/4,1]∪[0,1/4] already misses exactly 1/8).  With
r(O_m) = 2, the next octave has T-arc = [3/4, 1] ∪ [0, 1/4], so
T ∩ (bottom L2 of O_{m+1}) ≤ 2^{m+1}/4, and writing t = a/2^m ∈
(1, 13/8]: missed ≥ max(0, 2t − 5/2)·2^m + max(0, 3/2 − t)·2^m ≥
2^m/4.  ∎  (Same for the other team: its pattern is the same rotation
two quarters ahead.)  Machine-exact sharp form [e132 partU + e174
partROTB]: max_a (6·|T ∩ (a, 2a]| − 5a) = 0 for BOTH teams over
32 ≤ a ≤ 2^16 — sup window density exactly 5/6, attained, never
exceeded, with the per-octave maxima following the 4-phase law
4/7, 1/2, 4/5, 5/6 cycling with m mod 4 (A) and m+2 mod 4 (B).
Hence: for every C, neither team has a C-clean ratio-2 window at any
anchor with a > 6C.  "Near-clean windows" fail for every horizon.

**(R3) Doubling-subcritical, both teams, EVERY finite reflector
family.**  Hand proof.  Let w = 2u − f, f ≥ 1, u ∈ O_m,
2^{m+1} > 4(f − 1).  (a) If w ∈ O_{m+1} (all u except the bottom
band p_u ≤ (f−1)/2): p_w = 2p_u + 1 − f, giving the EXACT phase
identity  4p_w/2^{m+1} = 4p_u/2^m − 4(f−1)/2^{m+1}.  So q(w) ∈
{q(u), q(u) − 1} and r(w) = r(u) − 1 or r(u) − 2 (mod 4).  An A-step
needs r(u), r(w) ∈ {0,1}: only r(u) = 1 → r(w) = 0 qualifies (the
quarter-drop branch lands at r = 3 ∉ A).  From r = 0 no A-step
exists.  A B-step needs r(u), r(w) ∈ {2,3}: only r(u) = 3 → r(w) = 2;
from r = 2 no B-step exists.  (b) If w ∈ O_m (bottom band): w lies in
the top quarter, q(w) = 3, q(u) = 0; membership of both endpoints
forces m ≡ 3 (A) resp. m ≡ 1 (B) (mod 4), and the landing value has
r(w) = 0 resp. 2 — again terminal; and a value ARRIVING at a bottom
band via (a) has r = 0/2, which at m ≡ 3/1 is not in the team, so
(b) cannot be chained after (a).  Hence every in-team doubling chain
makes ≤ 2 steps once 2^{m+1} > 4(max F − 1) — for any finite F, all
chains from any seed are finite: **no infinite orbit, in either team,
for any finite reflector family** — a stronger conclusion than
lem:orbit's hypothesis needs (membership of reflectors is not even
used).  ∎  Machine: e131 subcrit (censored closures die, nodes ~10³,
top octave 11) and e132 partU2 — adversarial f ∈ [1, 64], all seeds
in (2^10, 2^11], horizon 2^22: all chains die, **max depth 1**, both
teams.

**Conclusion: L1' is REFUTED.**  ROT4 satisfies every hypothesis
(everywhere-split; both teams subcritical) and violates the
conclusion at every anchor and every horizon.  The stronger proof
target of notes/46 ("positive density in every window + no C-clean
windows ⇒ infinite doubling orbit") is refuted a fortiori: ROT4
teams have density ≥ 1/6 − o(1) in every ratio-2 window and no orbit.

### II.3 The obstruction, characterized

What L1' missed is a third concentration regime: **concentration in a
rotating frame**.  The doubling flow is phase-PRESERVING (the exact
identity in R3), and fixed ratio-2 windows are phase-blind; rotation
de-synchronizes team membership from both at once — each doubling
step loses one quarter of phase alignment, each window straddles two
octaves whose team-arcs are misaligned by one quarter.  The knobs are
sharp [e132 partU3 controls]:

* ROT2 (half-octave rotation): windows anchored at 3·2^{m−1} are
  EXACTLY clean (sup density = 1 at a = 48) — half-rotation
  re-synchronizes with ratio 2; Case-1 feed, L1'-compatible.
* ROT4: sup 5/6 (the counterexample).
* ROT8: sup 3/4 (an even more diffuse relative).

So rotation SUFFICES to defeat "subcritical ⇒ concentrated" for any
rotation order k ≥ 3-ish; what structure is NECESSARY for a
counterexample remains open and is deliberately NOT re-conjectured
here (no repaired L1'' is proposed: none is load-bearing).
